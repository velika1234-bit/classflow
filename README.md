# 🎓 ClassFlow — Интерактивна класна стая

Реално приложение за интерактивни уроци с PDF презентации, анкети, облак от думи, рисуване и AI оценяване.

---

## 🚀 Публикуване стъпка по стъпка (безплатно, ~20 минути)

### Стъпка 1 — Supabase (база данни + real-time)

1. Отиди на **https://supabase.com** → Sign Up (безплатно)
2. Натисни **New Project** → въведи име: `classflow`
3. Изчакай ~2 минути докато се създаде
4. Отиди в **SQL Editor** (лявото меню)
5. Копирай цялото съдържание на файла `supabase/migrations/001_schema.sql`
6. Постави го в SQL Editor и натисни **Run**
7. Отиди в **Settings → API** и копирай:
   - `Project URL` → това е `SUPABASE_URL`
   - `anon public` key → това е `SUPABASE_ANON_KEY`

### Стъпка 2 — Anthropic API ключ (за AI оценяване)

1. Отиди на **https://console.anthropic.com**
2. **API Keys → Create Key**
3. Копирай ключа → това е `ANTHROPIC_API_KEY`

### Стъпка 3 — Vercel (хостинг)

1. Отиди на **https://vercel.com** → Sign Up с GitHub акаунт
2. Натисни **Add New → Project**
3. Качи папката `classflow` или свържи с GitHub repo
4. В **Environment Variables** добави:
   ```
   NEXT_PUBLIC_SUPABASE_URL = https://xxxxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJxxx...
   ANTHROPIC_API_KEY = sk-ant-xxx...
   ```
5. Натисни **Deploy** → изчакай ~2 минути
6. Получаваш линк: `https://classflow-xxx.vercel.app`

## 💡 Как се използва

### Учителят:
1. Отвори `https://your-app.vercel.app`
2. Въведи заглавие на урока
3. Натисни **▶ Стартирай сесия** — получаваш PIN код и QR код
4. Качи PDF презентацията (бутон "Качи PDF")
5. Добави интерактивни слайдове: анкети, облак от думи, рисуване, свободни отговори
6. Навигирай между слайдовете — учениците виждат текущия слайд в реално време

### Учениците:
- Сканират QR кода **или** отиват на `your-app.vercel.app/join/XXXXX`
- Въвеждат PIN и своето име
- Виждат слайдовете синхронизирано с учителя
- Гласуват в анкети, пишат думи, рисуват, отговарят на въпроси

### AI оценяване:
- При свободни отговори, AI (Claude) автоматично оценява:
  - Релевантност към темата
  - Правилност на отговора
  - Дава оценка 0-100 и кратък коментар на български

## 📁 Структура на проекта

```
classflow/
├── pages/
│   ├── index.js              # Учителско табло
│   ├── join/[pin].js         # Страница за влизане на ученици
│   ├── student/[sessionId].js # Ученически изглед
│   └── api/
│       └── grade-answer.js   # AI оценяване (Claude API)
├── lib/
│   └── supabase.js           # Supabase клиент
├── styles/
│   └── globals.css           # Глобални стилове
├── supabase/
│   └── migrations/
│       └── 001_schema.sql    # База данни схема
└── .env.example              # Шаблон за environment variables
```

## 🔧 Локално стартиране (за разработка)

```bash
# 1. Инсталирай зависимостите
npm install

# 2. Копирай environment variables
cp .env.example .env.local
# После попълни стойностите в .env.local

# 3. Стартирай
npm run dev

# 4. Отвори http://localhost:3000
```
